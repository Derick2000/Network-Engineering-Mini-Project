# Network-Engineering-Mini-Project
Hands-on networking mini-projects using Cisco Packet Tracer

## About This Repository
This repository contains networking mini-projects completed as part of my practical learning in computer networking using Cisco Packet Tracer.

## Projects

### 1. LAN Implementation Using DHCP Server
- **Objective:** Automatically assign IP addresses to network clients.
- **Concepts:** LAN, IPv4, DHCP, connectivity testing.
- **Files:** Topology, configuration, and test results.

### 2. Network Implementation Using Remote Access Protocols
- **Objective:** Practise remote access and device administration.
- **Concepts:** SSH, Telnet, remote device management.

### 3. WAN Design Using a Routing Protocol
- **Objective:** Connect multiple networks through a WAN topology.
- **Concepts:** Routing, router configuration, routing tables.

### 4. WAN Design Using Dynamic NAT
- **Objective:** Practise translating private IP addresses using Dynamic NAT.
- **Concepts:** NAT, inside/outside interfaces, address translation.

### 5. Network Implementation Using Port Security and EtherChannel
- **Objective:** Practise switch port security and link aggregation.
- **Concepts:** MAC address security, EtherChannel, switching.

### 6. VLAN Infrastructure Design with DHCP
- **Objective:** Segment a network using VLANs and configure automatic IP allocation.
- **Concepts:** VLANs, DHCP, switching, IP addressing.

## Tools and Technologies
- Cisco Packet Tracer
- IPv4 and TCP/IP
- DHCP, VLAN, Routing, NAT
- Network troubleshooting

## Project Documentation
Each project folder contains its topology, relevant configuration, and testing evidence where available.
